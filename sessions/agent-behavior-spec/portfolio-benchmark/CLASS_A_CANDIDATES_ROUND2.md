# Class-A confirmatory portfolio — control-won sourcing (round 2)

Goal of round 2: the SCARCE ingredient — cases where the plausible CHANGE LOST and the
status-quo CONTROL won (real_winner=control). These stress the sim's measured pro-change
tilt. Round-2 agent also REJECTED a hallucinated source (Booking WiFi-score anecdote — not
in the cited primary), and confirmed empirically that eng-blogs yield ~zero clean primary
control-won product-feature cases; the reliable vein is peer-reviewed marketing field RCTs.

## CONTROL-WON (real_winner = control) — round 2
- **lambrecht_tucker_dynamic_retargeting_2013** — STRONG. Generic banner beats dynamic
  product-specific retargeting on avg (reverses only once preferences crystallize). JMR
  2013 50(5):561-576, DOI 10.1509/jmr.11.0503. N=77,937, 21d. memo=medium. THE cleanest
  "smarter/richer change loses" pro-change-tilt trap.
- **anderson_simester_installment_billing_2001** — STRONG. Adding an installment-billing
  offer LOWERS demand (adverse quality signal on a prestige catalog). Marketing Science
  2001 20(3):315-327, JSTOR 3181615. Field test + survey. memo=medium.
- **algesheimer_ebay_community_participation_2010** — STRONG. Community invitation raises
  participation ~23pp but participation has NEGATIVE effect on spend + listings. Marketing
  Science 2010 29(4):756-769, DOI 10.1287/mksc.1090.0555. n=13,735, yearlong. memo=low.
  Engagement↔revenue divergence trap (ties to [[project-metric-blinded-retention-unreliable-for-harm]]).
- **dholakia_simonson_explicit_reference_points_2005** — MEDIUM-HIGH. Adding a "compare to
  similar items" advisory induces cautious bidding → worse seller outcome. Marketing Science
  2005 24(2):206-217, DOI 10.1287/mksc.1040.0099. memo=medium. (negative seller outcome
  partly inferred; full text paywalled.)
- **bing_social_media_integration_2017** — BORDERLINE (near-null, not measured negative).
  Added FB/Twitter SERP pane → negligible lift vs >$25M cost. HBR 2017 R1705E. memo=medium.
  Use only if "plausible feature fails to beat status quo" counts; else drop.

## Empirical scarcity finding (round 2)
3 independent search tracks converged: Kohavi corpus dominated by methodology artifacts +
already-excluded cases; company eng blogs (Netflix/Spotify/Airbnb/LinkedIn/Pinterest/Uber/
DoorDash/Wish/Yandex/Yelp/Etsy/Twitter/Meta) yielded ZERO clean primary control-won
product-feature cases; one anecdote was a hallucinated search summary. => control-won
counterintuitive cases are genuinely rare (publication bias). Best remaining vein: more
adverse-signal marketing RCTs (Anderson/Simester signaling family; "sale"/discount signage
backfiring on quality-uncertain goods; loyalty/incentive features that depressed demand).
Round 3 (in flight): chase 3-4 more control-won in that family.

## Refined PRIMARY ENDPOINT for the confirmatory run
At true ~0.70, headline-significance is underpowered at any feasible n (control-won cases
too scarce for n~30). So the prereg's PRIMARY endpoint = CONTROL-CLASS accuracy on the
FRESH control-won cases: does the sim RESIST its pro-change tilt (>=~0.5) or COLLAPSE
(~0/n)? Even n=8 control-won is decisive. Secondary = headline dir_acc + rank_rho + per-class.
