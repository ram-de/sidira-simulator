METHOD — HOW THIS READING IS COMPUTED

AGREEMENTConfidence-weighted mean of per-agent sentiment, shrunk toward neutral (Bayesian), penalized by weakness share, scaled 0–100. Raw simulation reading — no live-outcome calibration has been applied (ledger empty), so the verdict stays directional.
INTERVALBootstrap percentile interval over agents; deterministic for a given run seed.
LIFTPaired bootstrap over per-agent sentiment deltas (treatment − control), in confidence points. Unpaired or unclassifiable agents are dropped from the statistic and counted in the drop note.
DECISION RULEDR-1 — DIRECTIONAL · TEST FIRST WHEN AGREEMENT ≥ 80 / 100 ON AN UNCALIBRATED READING. "Ship" is reserved for a graded ◆ reading once live outcomes populate the ledger. Display rubric applied by this page; the API does not return a policy object.
MODELRan on Llama 3.3 70B (Groq). Reactions, classifiers, and lift reflect this model; comparing runs across models should be read as model variance, not only product variance.
