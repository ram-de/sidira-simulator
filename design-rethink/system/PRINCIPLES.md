# SIDIRA — Design Principles · THE READING CONSOLE

Seven crisp laws. If a decision conflicts with one of these, the principle wins.

---

### 1. The spectacle is the computation.
Every effect must amplify the one truth this product owns — *it simulates a
population reacting to a change* — or it does not ship. The Population Field is a
live, honest visualization of the actual computation, not a metaphor bolted onto
it. If an animation can't be read as "the instrument is taking a reading," cut it.

### 2. Every reading wears its uncertainty.
A bare number is forbidden on any results surface. Each reading carries its CI
(`±`), its calibration glyph (◇ uncalibrated · ◆ graded), and its provenance.
Doubt has its own first-class color (`--spread`). We render honesty as a feature
that disarms the skeptic — never as fine print to dismiss.

### 3. Dark is a live estimate; light is a printed fact.
Console (dark `#0B1220`) means a live, computed reading. Sheet (light, cool
blueprint — never cream) means an archival record. The theme split is
load-bearing ontology, learned through color temperature. Mode is locked per
route; it never inverts mid-scroll.

### 4. Color carries meaning, never mood.
Signal-lime = a live reading (one carrier per region, it is light not paint).
Spread-amber = doubt. Arm tints = which experiment arm (identity, never valence —
a negative reaction renders in plain ink, never alarm-red). Semantic color rides
1px borders + the word, never a fill. Reach for a color that means none of these
and you are decorating — stop.

### 5. Numbers get the typewriter.
Geist for voice, Geist Mono with tabular numerals locked on for every score, CI,
seed, id, and tick — so figures never jitter and read with an instrument's
authority. Newsreader serif appears only in genuine record prose on Sheet, and
nowhere on Console. No font sprawl.

### 6. Everything settles or stays still.
A reading settles (trace converges, number counts to rest); a record is still.
There is no third motion, and nothing loops for decoration — the running status
dot is the only sanctioned infinite loop. No bounce, no elastic, no spring: an
instrument does not wobble. Uncalibrated data is dim and drifting and *never
settles* — it cannot fake a verdict.

### 7. Dense but calm; cut metal, not floating cards.
Rank information (one hero number, everything else recedes) instead of removing
it. Tight rhythm inside a region, generous silence between. Elevation is
lightness-step + a 1px inner highlight — never a drop shadow. Hairlines and
negative space group before a card does; a card earns itself only as a discrete
record, and cards never nest.
